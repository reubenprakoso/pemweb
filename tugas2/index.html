Tentang ITERA

Institut Teknologi Sumatera atau ITERA merupakan perguruan tinggi yang menjadi tema utama pada website sederhana ini. Halaman ini dibuat untuk menerapkan struktur HTML semantik dalam Tugas 2 Pengembangan Aplikasi Web.

Pendidikan

Pendidikan merupakan salah satu bagian penting dalam kegiatan perguruan tinggi. Mahasiswa dapat mengikuti proses pembelajaran untuk mengembangkan pengetahuan dan keterampilan.

Teknologi dan Inovasi

Bidang teknologi dan inovasi dapat dikembangkan melalui pembelajaran, praktikum, penelitian, proyek, dan kegiatan mahasiswa.

Kegiatan Kampus

Kegiatan Akademik

Kegiatan akademik dapat berupa perkuliahan, praktikum, seminar, penelitian, dan kegiatan pembelajaran lainnya.

Kegiatan Mahasiswa

Mahasiswa juga dapat mengikuti berbagai kegiatan organisasi, pengembangan diri, kompetisi, dan kegiatan lainnya.

Contoh Kegiatan

  • Perkuliahan
  • Praktikum
  • Seminar
  • Organisasi mahasiswa
  • Kompetisi teknologi

Informasi Singkat

HTML

HTML merupakan bahasa markup yang digunakan untuk menyusun struktur sebuah halaman web.

HTML Semantik

HTML semantik menggunakan elemen berdasarkan fungsi dan makna kontennya sehingga struktur halaman lebih mudah dipahami.

Elemen Semantik

Website ini menggunakan elemen header, nav, main, section, article, aside, dan footer.

Tujuan Penggunaan

Penggunaan elemen semantik bertujuan membuat struktur halaman lebih terorganisir dan mudah dipahami.

Catatan Tugas

Halaman ini dibuat sebagai implementasi Tugas 2 Pengembangan Aplikasi Web.
